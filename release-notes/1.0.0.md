# Mnemic 1.0.0

Mnemic 1.0.0 is the first release: a document database server with a schema, a query language that reads like SQL, and the history of every temporal document, with a typed client for .NET and Studio, its graphical client.

## What it holds

- **Typed documents.** A collection declares its fields, nested objects and arrays, enums, composite types with inheritance, and subtypes. Every write is held to the collection's primary key, its references and its CHECK constraints.
- **MQL.** Joins, grouping and aggregates, window functions, common table expressions, subqueries, vector search and `EXPLAIN`, in a language whose statements begin with their source and end with their projection.
- **Temporal collections.** Every version of a document is kept: read a collection as of any instant, list the versions over a range, and write a version that starts in the past or the future.
- **Transactions and migrations.** Writes in a transaction commit or roll back as one, and schema changes run as migrations that apply whole or not at all.
- **Indexes.** Secondary indexes with compound keys, covering fields and partial predicates, unique indexes, indexes over array elements, online builds, and an optional approximate vector index.
- **Views, triggers and subscriptions.** Views and materialized views, triggers that run in the transaction of the write that fired them, and change notifications to clients of the server.
- **Operations.** Online backup, verified restore, WAL archiving with point-in-time recovery, online verification, and health monitoring that quarantines a faulted part of a database.
- **Security.** Mandatory authentication, users and roles granted per database, TLS by default with certificate pinning, and an audit log.
- **The server.** A Linux container image, `ghcr.io/mnemic/mnemic`, that runs as a non-root user and supports a read-only root filesystem.
- **Clients.** The .NET client in `Mnemic.Client.Remote`, the embedded engine in `Mnemic.Client.InProcess`, and Studio, as a Windows desktop application and as a server plugin.
